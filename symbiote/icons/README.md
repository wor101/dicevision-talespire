# Icon Requirements

Talespire requires a 64x64 PNG icon named `icon_64.png`.

## Creating the Icon

1. Use the provided `icon_64.svg` as a template
2. Convert to PNG using one of these methods:

### Using ImageMagick (command line)
```bash
convert icon_64.svg icon_64.png
```

### Using Inkscape (command line)
```bash
inkscape icon_64.svg --export-filename=icon_64.png --export-width=64 --export-height=64
```

### Using online tools
- https://cloudconvert.com/svg-to-png
- https://svgtopng.com/

### Using graphics software
- Open `icon_64.svg` in GIMP, Photoshop, etc.
- Export as PNG at 64x64 pixels

## Icon Design

The icon shows:
- Purple circle background (#5865f2 - matches Talespire accent)
- D20 die outline
- Camera lens indicator at bottom

Feel free to create a custom icon following your brand guidelines!
